01 / FIRST READ

先记住四个判断

物理AI不是一个零部件，也不只是人形机器人。它是一套让机器在真实环境中感知、决策、行动，并从结果中学习的系统。

训练链与制造链并行

训练链解决“怎样学会做”；制造链解决“怎样可靠地动”。数据、仿真需求可能先于整机大规模出货，也可能随训练方法变化而改变。

原始采集不是成品数据

视频、深度、姿态、力觉要完成同步、标注、质量检查和动作重定向，才能支持特定训练任务。单纯视频素材不等于机器人动作数据。

整机收入最直观，利润未必

整机有交付和验收，却承担集成、售后、场景适配与资金占用。上游也可能有利润，但必须看实际订单、价格和产能利用率。

题材标签不等于合同

与英伟达技术适配、参加生态、产品送样、批量交付和独家量产供货，是不同证据等级。本文不给未经证实的公司之间画采购箭头。

阅读重点：先看三张图，再看奥比中光、华依科技、利亚德/凌云光、索辰科技、兆威机电、埃斯顿与东方精工的区别。这里的“核心”指理解链路的重要性，不是股价排名。

依据公司产品/定期报告与官方技术材料；产业结构截至整理日检索，本文未进行实时行情、估值或买点判断。长图未见可确认的券商署名、分析师与完整发布日期，本文称其为“用户提供的长图资料”，不认定为已鉴真的正式券商研报。

02 / YOUR THREE ROUTES

把截图的1—3，翻译成三条产业逻辑

① 数据瓶颈：机器先要“学过”

原始动作和环境 → 清洗标注 → 场景/物理属性 → 训练与评测 → 真机反馈。涉及感知器件、采集设备、数据服务和仿真工具，不是把名单中的公司首尾串成一条已发生的供货链。

纠正：奥比是3D视觉层；索辰是仿真/软件层；华依是IMU层；思特威是图像器件层。截图的“2、3”占位缺少定义，本文按标准工程流程补全，未猜测讲者原意。

② 零部件：从“学会”到“做得稳”

兆威机电代表微型驱动/灵巧手等执行方向。模型进步不能替代电机、传动和力控的可靠性；批量交付会影响零部件需求，但技术路线与单机用量可能变化。

注意：“轮动预期”讨论的是股票资金可能扩散，不是产品订单已经出现。

③ 整机与落地：谁能把系统交付给客户

埃斯顿主要看工业机器人和自动化；东方精工要拆控股产线与参股生态；宇树是实际本体产品主体。它们不能简单同列为“人形整机、都已赚钱”。看收入之后，还要看毛利、售后、现金流和客户回本周期。

03 / DATA LOOP

架构图一：机器人怎样从数据中学会任务

真实数据提供接触、遮挡、摩擦等约束；仿真能低成本覆盖更多环境和失败情况。二者是互补关系，不是“虚拟世界替代所有真实采集”。NVIDIA把训练、仿真/合成数据、真机运行分为三类计算平台。[1]

术语解决的问题不能混淆
数字孪生建立与真实对象对应的数字模型，映射状态或支持分析仅可视化的3D模型，不一定具备训练所需物理精度
物理仿真计算碰撞、重力、摩擦、关节等行为，测试控制策略可用于工程验证，不必然包含生成式世界模型
世界模型学习或预测环境状态如何变化，可用于生成数据、推演与评估不保证预测严格符合物理，更不等于完整机器人控制器
VLA将视觉、语言与动作关联，用任务描述和观察形成动作输出还需动作约束、底层控制、硬件与安全系统
IMU测量加速度、角速度等，辅助姿态/运动估计不直接测出绝对位置；漂移和融合算法很重要
动捕 / 遥操作前者记录动作；后者让人实时操纵机器并记录示范人体骨架与机器人关节不同，通常需要动作重定向

参考技术平台：Isaac Sim偏仿真与测试，Isaac Lab偏策略训练，Cosmos偏世界模型及数据工具；它们与整机厂、软件企业不是同一类业务。[2] [3]

04 / VALUE CHAIN

架构图二：真实机器人的上下游分工

读图规则：同一栏是同层功能举例，不代表公司之间已经供货。思特威与奥比中光存在功能上的器件—系统层级差别，但本次未确认两者采购关系。具体客户、独供及份额须另查合同或公告。

感知链

图像芯片/光学 → 相机或深度系统 → 感知算法 → 模型与控制。IMU和力觉是并行输入，不必全部经过视觉厂商。

运动链

策略/控制器 → 驱动电路 → 电机 → 减速/丝杠等传动 → 关节与末端。不同结构有不同组合，并非每台机器都采用同样BOM。

05 / LEARN BY ONE TASK

例子：让机器人“拿起杯子，放到架子上”

  1. 采集示范：人通过头戴设备、相机或动捕记录操作；有本体时，可记录机器人关节、视觉和力觉。创维、利亚德、凌云光等对应不同采集方式。
  2. 整理数据：对齐时间戳与坐标，标出杯子、接触、成功/失败，剔除错误轨迹；人体动作要转换到机器人可执行空间。海天瑞声、天娱等属于相关数据/平台层举例。
  3. 虚拟训练：给杯子和架子设置几何、质量、摩擦与碰撞属性，更换光照和位置，反复评测。索辰、凡拓对应相关软件/场景能力，能否满足具体精度需测试。
  4. 真机执行：奥比类深度视觉估计位置，IMU辅助姿态，力觉判断夹持力度；策略经控制器、驱动和执行器落实。兆威代表末端微型驱动方向。
  5. 客户验收：检查成功率、节拍、破损率和人工替代成本。失败样本再回流训练，构成闭环。

以上是教学功能例子，未指称这些公司共同参与同一个杯子抓取项目，也未指称各自与某本体厂签署合同。

公司逐一解析：位置、变现与证据边界

奥比中光688322感知与采集 · 3D视觉传感器与方案

帮助机器人知道物体在哪、距离多远、空间形状如何。它是“眼睛和深度感知”，不是机器人整机。

上游输入

下游需求

披露证据
公司自述公司披露Gemini 330系列与NVIDIA Jetson Thor进行集成适配。[5]
变现路径

后续验证
机器人应用出货、客户验证、单机价值量、毛利率与回款。
不能推出
“适配英伟达”不等于英伟达直接采购；不能称所有机器人都绕不过去，也不能画成每家整机的既定供应商。

付费客户、验收、产品收入拆分、研发投入与应收账款。

需求增长 → 客户验证 → 订单 → 交付验收 → 收入 → 毛利 → 扣除研发、销售与售后成本 → 利润与现金回款。

10 / USE THIS IN YOUR RESEARCH

以后看一条消息，就问这六个问题

  1. 新增需求在哪一层？训练数据、数采设备、仿真、关节还是整机？不要把一个利好平均分给整条链。
  2. 公司以什么产品接住？说出产品名、使用场景和付费方，不能只说“有机器人概念”。
  3. 进展到哪一步？研发→样品→验证→小批量→批量→收入→回款，逐项记录，不跳级。
  4. 经济利益属于谁？上市公司本体、控股子公司，还是少数股权投资？会计口径不同。
  5. 什么会使逻辑失效？客户不复购、方案被替代、单价降得快、良率差、验收/回款延迟。
  6. 产业判断能否支持当前价格？产业相关性只回答“研究谁”；买卖仍需新的行情、估值、量价与退出条件。

研究顺序建议（不是买入排序）

第一组：奥比、华依、思特威、利亚德/凌云光——搞懂传感器、模组与数采系统的层级。
第二组：索辰、凡拓、天娱、海天、创维——区分仿真、数据服务和设备。
第三组：兆威、汇川、绿的、双环、柯力——区分动力、传动、控制与力觉。
第四组：埃斯顿、东方精工、宇树——看整机、产线、股权关系和真实客户付费。
