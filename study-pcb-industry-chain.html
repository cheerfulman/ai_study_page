PCB 上下游产业链全景梳理

材料 · 板材 · 工艺 · 载板 · 玻璃基板 —— 一条主干、两条支线，以及每个模块在"现在 / 未来"坐标系里的位置

一、总纲：这条链为什么在重构

PCB 原本是个偏加工的制造业，AI 算力把它变成了材料科学 + 半导体工艺。整条链上所有的升级，本质上只被两个指标拽着走：信号频率和线宽。

频率↑ → 损耗 Df 必须↓ → 树脂 / 布 / 铜箔三件套全套换代（M6→M7→M8→M9）
线宽↓ → 起点铜必须越薄 → 工艺从减成法走向半加成法（mSAP / SAP）
载体做到极限 → 有机树脂（ABF）触顶 → 换成玻璃（TGV）

所以判断任何一个模块值不值得看，只需要三个问题：

  • 是不是卡脖子——供给刚性有多强，扩产周期多长；
  • 有没有认证壁垒——拿到英伟达 / 头部客户认证的有几家，会不会被快速替代；
  • 放量落在哪一年——2026 兑现、2027 兑现，还是 2029 的期权。

对应的一条通用规律：上游稀缺材料 > 中游覆铜板 > 下游 PCB 加工 > 设备（弹性从大到小，确定性从低到高）。这轮周期利润明显在向上游材料转移。

二、主链路思维导图

第 1 层 · 上游主材（决定天花板）
玻纤 → 电子布
矿物池窑拉丝成玻纤纱 → 织造成电子布（7628 / 2116 / 1080 为厚度规格）。CCL 的"骨架"，管尺寸稳定与强度。
大宗存量普通 E 布是周期品，本轮涨价是高端挤占织机产能后的外溢
宏和科技（薄布/超薄布）、林州光远（低介电）、中材科技、中国巨石、国际复材；海外日东纺
Q 布（石英布）
高纯石英拉丝织布。Dk≈2.8–3.1、Df 极低、CTE 极低。
现在 · 最缺M9 唯一解：Df≤0.0009、78 层不变形，普通玻纤物理做不到
菲利华（国内独家量产 AI 级）、石英股份（石英砂原料）、中材科技（偏 M8.5 档）
树脂
CCL 的胶粘剂兼绝缘体，Df 主要由它决定。溴化环氧 → PPO / 碳氢 / BMI → 加 PTFE。
现在 · 最缺PTFE 是下一棒M8→M9 碳氢:PTFE 由 1:2 提到 2:1
东材科技（全球唯二、国内唯一通过英伟达 M9 碳氢认证）、圣泉集团（PPO）、同宇新材、宏昌电子、联瑞新材（填料）
铜箔 → HVLP
电解/压延成箔，按表面粗糙度分级 HTE → RTF → VLP → HVLP（Rz≤0.4μm）。趋肤效应下表面越糙损耗越大。
现在 · 缺口 20%+HVLP4 是当前主力，HVLP5 对应 2027 超高层
铜冠铜箔（HVLP4 进 M9 链）、德福科技、隆扬电子（HVLP5）、中一科技、诺德股份
可剥铜（载体铜箔）
载体层 + 剥离层 + 1.5–3μm 超薄铜层。压合后撕掉载体，留超薄铜作为 mSAP 的起点铜。
国产替代 0→1工艺门票级耗材，此前几乎由三井金属垄断
德福科技、华威铜箔（安徽）、中一科技、铜冠铜箔；海外三井金属、福田金属
三大主材必须同步升级才能做出 M9 —— 任一块短板都会卡住整条链的产出，这就是"木桶效应"。

第 2 层 · 覆铜板 CCL（利润中枢）
覆铜板 CCL　＝　树脂 + 玻纤布 + 铜箔 + 球形硅微粉填料，高温压合
等级沿用松下 MEGTRON 代号：FR-4 → M6/M7 → M8 → M9 → M10。M9 单价比 M8 高 2.8–3.5 倍，毛利率 40%–48%（普通 FR-4 仅 18%–25%）。
量价齐升最确定壁垒：英伟达全链路认证 12–18 个月，全球仅 4 家拿到 Rubin 正式资质；单线资本开支 20 亿+、建设 2 年
生益科技（大陆唯一英伟达 M9 批量认证）、南亚新材（昇腾全系认证，弹性大）、华正新材、金安国纪、建滔积层板；海外台光电（M9 份额约 40%）、松下、斗山
▼
第 3 层 · 线路成形工艺（决定线宽）
减成法（>30μm） → HDI → mSAP（15–25μm） → SAP（<15μm，载板标准）
核心原理一句话：起点铜越薄，闪蚀的侧蚀越小，线宽就能越细。mSAP 用 2–3μm 可剥铜替代溅射种子层，在精度与成本间取平衡。
渗透率快速爬坡800G 渗透率已近一半，1.6T / 3.2T 是 100% 采用；层数 14→24 层，增层越多 mSAP 工序重复越多。门槛：每万平方米设备投资 6–7 亿，是传统 HDI 的 4–5 倍
能做 mSAP：鹏鼎控股（苹果 SLP 经验可复刻）、深南电路（国内第一大 BT 载板厂 + 第一大 mSAP 光模块厂）、东山精密（索尔思）、沪电、胜宏；海外欣兴、AT&S、美维。配套设备：激光钻孔、LDI 曝光、VCP 电镀、AOI

第 4 层 · 成品与载体
PCB 厂商
CCL + 半固化片 PP → 压合 / 钻孔 / 电镀 / 蚀刻 → 成品板。形态：高多层板、背板、HDI、SLP。
需求验证环节单机柜 PCB 价值由约 3.5 万美元升至约 11.7 万美元（Rubin），但利润正向上游转移
胜宏科技（M9 最大消耗端，计算托盘份额高）、沪电股份（78 层背板 / 谷歌交换机）、深南电路、生益电子、广合科技、东山精密、鹏鼎控股、景旺电子
IC 载板：ABF · BT
芯片与 PCB 之间的中介层，线宽 10–20μm，必须 SAP/mSAP。ABF 用味之素堆积膜做介质，服务 CPU/GPU；BT 用三菱瓦斯化学 BT 树脂 + 玻纤布，服务存储 / 手机 / 射频。
当前最高端 · 缺口最大2026–2028 供需缺口持续扩大，国产替代加速
深南电路（国内第一大 BT 载板厂，ABF 同步放量）、兴森科技（ABF + 存储）、珠海越亚、科睿斯（FCBGA 高端 ABF）；海外欣兴、Ibiden、Shinko、三星电机、景硕
玻璃基板（未来）
玻璃原片 → 激光改质 → 湿法蚀刻成 TGV 通孔 → PVD 种子层 + 电镀填孔 → CMP + RDL 多层布线 → AOI。
未来 · 2027 起量2026 商业化元年，2028 规模量产，CPO 相关 2029–2030。当前良率约 70%，比 ABF 低 20–30pct
沃格光电（TGV 领先，约 1 万片/月，1.6T CPO 已量产供货）、蓝思科技（英特尔 MOU，最小孔径 10μm）、美迪凯、京东方 / TCL 华星 / 深天马（面板厂跨界）；原片：力诺药包、康宁、AGC
▼
第 5 层 · 需求端（拉动源）
AI 服务器（Rubin / GB 系列） · 1.6T / 3.2T 光模块 · 高速交换机 · HBM / 存储 · CPO / NPO
AI 是唯一的核心变量。行业规模 2024 约 800 亿美元 → 2025 约 840–850 亿 → 2026 预计 940–980 亿美元。扩产周期 1.5 年，2024 下半年启动的产能 2026 下半年才有效释放，因此全年高稼动率确定性高。

四、玻璃基板：为什么它"里面长出"了激光设备

玻璃基板不是一个单点产品，而是一整套全新制造流程，其中第 2 步"激光改质"是整条线的设备核心——这就是激光设备会成为独立子模块的原因。

激光设备的双重落点——它是唯一横跨"现在"与"未来"的环节：

  • 现在的落点：AI PCB 的激光钻孔、CCD 背钻、超快激光（1.6T 光模块已订单突破）→ 大族数控（钻孔机）、鼎泰高科（钻针）、大族激光
  • 未来的落点：TGV 激光改质 / 成孔设备 → 帝尔激光（已出货并有复购）、大族激光、德龙激光、英诺激光
  • 配套：鼎龙股份（CMP 抛光垫）、艾森股份（电镀液 / 光刻胶）、路维光电（TGV 掩膜版）、奥来德（PSPI / 介质膜）、三孚新科（PLP 镀铜设备）

设备的确定性高于材料（只要行业扩产就受益，不承担认证失败风险），但弹性小于材料——这是两者最本质的区别。

五、收总：三条主线与排序

主线一 · 现在最硬（2026–27 兑现业绩）

M9 材料升级链条，逻辑最硬、可跟踪性最强

  • 上游稀缺材料：东材科技（碳氢树脂）、菲利华（Q 布）、铜冠铜箔（HVLP4）
  • 中游覆铜板：生益科技（首选底仓）、南亚新材（昇腾弹性）
  • 下游验证：胜宏科技、沪电股份（看订单与稼动率）

主线二 · 国产替代 0→1（现在）

供给被海外垄断、正在突破的环节

  • 载板：深南电路、兴森科技、科睿斯
  • 可剥铜：德福科技、华威铜箔、中一科技
  • mSAP 产能：鹏鼎控股、深南电路、东山精密

主线三 · 未来期权（2027–2030）

尚未贡献利润，看的是产业进展与验证节奏

  • 玻璃基板：沃格光电、蓝思科技、美迪凯
  • TGV 设备：帝尔激光、大族激光
  • 配套材料：鼎龙股份、艾森股份、奥来德、路维光电

需要盯住的几个观测指标

  • CCL 涨价函与传导是否持续（成本推动 vs 供需推动）
  • Q 布 / 碳氢树脂 / HVLP 铜箔的扩产节奏（2027 后是否集中释放）
  • 英伟达 Rubin 量产节奏与云厂商资本开支
  • 玻璃基板良率从 70% 向 90% 爬升的速度
  • ABF / BT 载板缺口比例、价格与交期变化

风险

  • 需求侧：AI 芯片出货与云厂商资本开支若不及预期，M9 订单会被整体下调
  • 供给侧：2027 年后碳氢树脂、石英布、HVLP 铜箔新增产能集中释放，高端溢价收窄，压缩 CCL 毛利率
  • 格局侧：更多内资 CCL 厂拿到 M9 资质后行业内卷降价
  • 技术路线：PTFE 氟树脂路线若提前大规模商用，会分流碳氢路线需求
  • 估值侧：上游材料标的短期涨幅过高，业绩未必同步匹配
